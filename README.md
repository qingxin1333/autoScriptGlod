# 知了快看自动领金币

ADB + RapidOCR 驱动的"知了快看"(new.liao.view) 看广告领金币自动化脚本。
截图 -> OCR 识别文字位置 -> 按状态机点击，无需固定坐标。

## 环境

- Python 3.10（本机 `py` 启动器可用）
- 依赖：`rapidocr_onnxruntime`、`opencv-python-headless`、`numpy`、`pyyaml`
  ```
  py -m pip install rapidocr_onnxruntime opencv-python-headless pyyaml
  ```
- ADB：`D:\AndroidSdk\platform-tools\adb.exe`（在脚本顶部 `ADB` 常量可改）
- 手机开启 USB 调试并连接

## 运行

```bash
cd /d D:\workSpaceAi\autoScriptGlod
py zhiliao_bot.py
```

参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--interval` | 2.5 | 截图轮询间隔秒 |
| `--stuck-sec` | 18 | 倒计时不动多少秒判定广告卡死 |
| `--max-loops` | 0 | 最大轮次，0=无限 |

`Ctrl+C` 停止。

## 状态机

| 界面 | 特征 | 动作 |
|---|---|---|
| 广告倒计时中 | `Xs\|跳过`、`X秒` | 等待 |
| 倒计时卡死 | 超时不走 + `我要加速/上滑或点击/查看详情` | 点CTA → 快轮询拦截框 → 点"仍要打开" → 外部浏览17s(自动下滑) → 切回 |
| 系统拦截框 | `已拦截/尝试打开` | 未领奖→"仍要打开"；刚领过→"取消" |
| 跳到外部APP | focus 不在 new.liao.view | 等10s切回 |
| 福利弹窗 | `放弃福利` | 点放弃，等倒计时 |
| 下载拦截 | `继续观看` | 点继续观看（不下载） |
| 奖励到账 | 顶部`领取成功/奖励已领取/恭喜获得奖励` + `跳过/关闭` | 点退出；无文字则点标题右侧X |
| 领奖弹窗 | `全部都要/开心收下/看视频再领` | 点击继续看下一个广告 |
| 金币弹窗 | `恭喜获得金币 +N` | 依次试:识别×→右上角→弹窗下方→返回 |
| 任务中心 | `领奖励/领取/可领取/开宝箱得金币` | 点击领任务 |
| 无CTA无倒计时 | 结束卡 | 轮流点右上角3个X位→返回→重启APP |

防死循环：同一广告救援4次未果→尝试X位+返回放弃；连续9次无效→重启APP；截图连续失败→自动 `adb reconnect`。

## 已知注意点

- "去浏览15秒"类广告**必须连续浏览满15s**，提前切回任务失败
- 部分落地页要求**下滑滚动**才计时（脚本已自动下滑）
- 绝不点 `下载/安装/打开淘宝/只领` 类文字（黑名单）
- 左边缘右滑手势 = 返回，可关掉跳转提示弹层
