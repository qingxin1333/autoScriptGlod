# 自动看广告领金币 (adbot)

ADB + RapidOCR 驱动的通用"看广告做任务领金币"自动化。
截图 -> OCR 识别文字位置 -> 按状态机点击，无需固定坐标。
广告处理逻辑(穿山甲/优量汇等SDK)各 APP 通用，差异集中在顶部 `APPS` 配置。

## 支持的 APP

| --app | APP | 包名 | 任务入口 |
|---|---|---|---|
| `zhiliao` | 知了快看 | new.liao.view | 底栏"赚零花" |
| `hongguo` | 红果免费短剧 | com.phoenix.read | 底栏"赚钱" + 红包10连开 |

## 环境

- Python 3.10（本机 `py` 启动器可用）
- 依赖：
  ```
  py -m pip install rapidocr_onnxruntime opencv-python-headless numpy
  ```
- ADB：`D:\AndroidSdk\platform-tools\adb.exe`（脚本顶部 `ADB` 常量可改）
- 手机开启 USB 调试并连接；**务必先手动把媒体音量/铃声音量关到静音**

## 运行

```bash
cd /d D:\workSpaceAi\autoScriptGlod
py adbot.py --app hongguo           # 跑红果
py adbot.py --app hongguo --rotate  # 收益枯竭自动轮换到下一个APP
```

参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--app` | hongguo | 目标APP |
| `--rotate` | 关 | 枯竭自动换APP |
| `--interval` | 1.0 | 截图轮询间隔秒 |
| `--stuck-sec` | 10 | 倒计时不动多少秒判定广告卡死 |
| `--max-earns` | 50 | 单APP领多少次后判枯竭 |
| `--idle-min` | 15 | 连续多少分钟无收益判枯竭 |
| `--max-loops` | 0 | 最大轮次，0=无限 |

`Ctrl+C` 停止。日志建议重定向 `> run.log 2>&1`。

## 状态机

| 界面 | 特征 | 动作 |
|---|---|---|
| 广告倒计时中 | `Xs\|跳过`、`X秒` | 等待 |
| 倒计时卡死 | 超时不走 + `我要加速/上滑或点击/查看详情` | 点CTA → 快轮询 → 放行跳转 → 外部浏览17s(下滑) → 切回 |
| 荣耀授权弹窗 | `想要打开...是否允许` | 主动CTA时勾"今日不再提醒"+点"允许"；否则"拒绝" |
| 系统拦截横幅 | `已拦截/尝试打开` | 同上逻辑："仍要打开"/"知道了" |
| 挽留弹窗 | `确定要退出/坚持退出/返回看视频` | 未领奖→留下继续看；已领奖/放弃中→坚持退出 |
| 跳到外部APP | focus 不在目标包 | 浏览15s(下滑)切回 |
| 福利弹窗 | `放弃福利` | 点放弃，等倒计时 |
| 下载拦截 | `继续观看` | 点继续观看（不下载） |
| 安装授权 | packageinstaller | 点"禁止"，永不安装 |
| 奖励到账 | 顶部`领取成功/奖励已领取/恭喜获得奖励` | 点"跳过/关闭"或标题右侧X |
| 领奖弹窗 | `全部都要/开心收下/看视频再领` | 点击继续看下一个广告 |
| 金币弹窗 | `恭喜获得金币 +N` | 识别×→右上角→弹窗下方→返回 |
| 更快拿奖弹层 | `我要更快拿奖` | 点按钮浏览15s领奖，最多2次 |
| 微信小程序窗 | MobRewardLoadPrompt/含"小程序" | 下滑浏览后点右上角X |
| 红包10连开(红果) | BulletContainerActivity | "选N金币"取大额；否则点"开" |
| 任务页 | `领奖励/去领取/开宝箱` | 点击领任务; 无可点任务下滑翻列表 |
| 结束卡 | 无倒计时无CTA | 轮流点8个X位→返回→拉主界面 |

防死循环：广告救援4次未果→放弃退出；挽留弹窗留下2次无效→转退出；
X位全无效→拉主界面；截图连续失败→`adb reconnect` 等待重连。
枯竭规则：单APP领奖≥`--max-earns`次 或 `--idle-min`分钟无收益 → `--rotate`换APP或退出。

## 已知注意点

- "去浏览15秒"类广告**必须连续浏览满15s**，提前切回任务失败
- 部分落地页要求**下滑滚动**才计时（脚本已自动下滑）
- 绝不点 `下载/安装/打开淘宝/只领/提现` 类文字（黑名单）
- 需要跳到**未安装的APP**的广告做不了（如手机没装抖音极速版时跳它）→救4次自动放弃
- 左边缘右滑手势 = 返回，可关掉跳转提示弹层
- `zhiliao_bot.py` 是知了快看专用旧版，新逻辑都在 `adbot.py`
